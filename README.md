# 🩺 Dashboard ผลวัดความดัน พนักงานขับรถ (TPT)

Dashboard แสดงผลการวัดความดันโลหิตและชีพจรของ พขร. กะ A / B
- **ภาพรวม**: KPI, กราฟจำนวนคนที่ความดันสูงรายวัน, ค่าเฉลี่ยทั้งกลุ่ม, ตารางสรุปรายบุคคล และตารางสีรายวัน
- **ค้นหา**: พิมพ์ชื่อ หรือทะเบียนรถ (เช่น `สมชาย`, `71-3416` หรือ `3416`) ในช่องค้นหา — ตาราง/กราฟภาพรวมจะกรองตามทันที กด Enter หรือคลิกรายชื่อเพื่อเปิดหน้ารายบุคคล
- **รายบุคคล**: เลือกจากช่องค้นหา (หรือคลิกชื่อในตาราง) เพื่อดูกราฟแนวโน้มความดัน ชีพจร และบันทึกรายวัน
- กรองตามกะได้ (ทั้งหมด / A / B) · รองรับมือถือ และโหมดมืด

- หน้าเว็บโหลดข้อมูลใหม่เองทุก 5 นาที (ไม่ต้องกดรีเฟรช)

## เกณฑ์ระดับความดัน (รพ.ศิริราชปิยมหาราชการุณย์ / WHO)
ใช้ระดับที่ **สูงกว่า** ระหว่างค่าบน (SYS) และค่าล่าง (DIA) · พขร. ขับรถได้เมื่อ **ไม่เกิน 140/90**

| ระดับ | SYS | DIA | วิธีปฏิบัติ |
|---|---|---|---|
| ความดันต่ำ | < 90 | < 60 | ขับได้ถ้าไม่มีอาการร่วม หากหน้ามืด ตาลาย ใจสั่น เป็นลม → **งดขับรถ** |
| ความดันที่ดี | < 120 | < 80 | ขับรถได้ตามปกติ |
| ปกติ | 120–129 | 80–84 | ขับได้ บันทึกและติดตามความดันสม่ำเสมอ |
| ค่อนข้างสูง | 130–139 | 85–89 | ขับได้ (ไม่เกิน 140/90) และติดตามสม่ำเสมอ |
| สูงเล็กน้อย | 140–159 | 90–99 | นั่งพัก ≥ 5 นาที วัดซ้ำ หากยังสูงแจ้งผู้รับผิดชอบ |
| สูงปานกลาง | 160–179 | 100–109 | พักและวัดซ้ำ หากยังสูง ส่งแพทย์ประเมินก่อนกลับไปขับ |
| สูงมาก | ≥ 180 | ≥ 110 | **งดขับรถ** ส่งประเมินทางการแพทย์ |

แก้เกณฑ์ได้ที่ตัวแปร `LEVELS` และฟังก์ชัน `levelOf` ใน `site/index.html`

## เปิดใช้งานบน GitHub Pages (ทำครั้งแรกครั้งเดียว)
1. Merge โค้ดเข้า branch `main`
2. ไปที่ **Settings → Pages → Build and deployment → Source** เลือก **GitHub Actions**
3. ไปที่แท็บ **Actions** → เลือก *Build & Deploy Dashboard* → **Run workflow** (หรือ push อะไรก็ได้เข้า main)
4. เมื่อเสร็จ จะได้ลิงก์ `https://<user>.github.io/<repo>/`

> ⚠️ ข้อมูลมีชื่อ-สกุลและข้อมูลสุขภาพ — GitHub Pages ของ repo สาธารณะ **ทุกคนเปิดดูได้**
> ถ้าต้องการจำกัดผู้ดู ให้ตั้ง repo เป็น Private (Pages แบบจำกัดสิทธิ์ต้องใช้ GitHub Enterprise) หรือเปิดใช้ภายในองค์กรแทน

## อัปเดตข้อมูล
1. บันทึกไฟล์ Excel ตามรูปแบบเดิม (ชื่อพนักงานขับรถ | ทะเบียนรถ | กะ | … | `วันที่ 1-30 /11/26` → บน / ล่าง / ชีพจร)
2. อัปโหลดไฟล์ไปที่โฟลเดอร์ `data/` (Add file → Upload files) — แทนที่ไฟล์เดิม หรือเพิ่มไฟล์เดือนใหม่ก็ได้
3. Commit เข้า main → GitHub Actions แปลงข้อมูลและอัปเดต Dashboard ให้อัตโนมัติ (~1 นาที)

สคริปต์อ่าน **ทุกชีตในทุกไฟล์** ใน `data/` แล้วรวมตาม ชื่อ + กะ (ข้ามแถวที่ไม่มีชื่อ)
เดือน/ปีอ่านจากหัวคอลัมน์ เช่น `วันที่ 1-30 /11/26` = พฤศจิกายน 2026

## อัปเดตอัตโนมัติจากโฟลเดอร์แชร์ `\\la26032\scan\...\31.ลงข้อมูลวัดความดัน พขร. TPT`
GitHub เข้าถึงโฟลเดอร์แชร์ในบริษัทไม่ได้ จึงต้องมี **คอมพิวเตอร์ Windows ในบริษัท 1 เครื่อง** (ที่เปิดโฟลเดอร์แชร์ได้)
คอยตรวจโฟลเดอร์ทุก 5 นาที ถ้าไฟล์ Excel มีการเปลี่ยนแปลงจะอัปโหลดขึ้น GitHub ให้เอง → Dashboard อัปเดตภายใน ~2 นาที

```
แก้ไฟล์ Excel ในโฟลเดอร์แชร์ ─► PC ในบริษัท (ตรวจทุก 5 นาที) ─► GitHub ─► Actions สร้างเว็บใหม่ ─► หน้า Dashboard รีเฟรชเอง
```

**ติดตั้ง (ทำครั้งเดียว บนเครื่องนั้น):**
1. ติดตั้ง [Git for Windows](https://git-scm.com/download/win) (กด Next ตามค่าเริ่มต้น)
2. เปิด PowerShell แล้ว clone repo ไว้ในเครื่อง เช่น
   ```powershell
   cd $HOME\Documents
   git clone https://github.com/godaresz/Dashboard.git
   cd Dashboard
   git config user.name "BP Sync"
   git config user.email "you@example.com"
   ```
3. รันซิงก์ด้วยมือ 1 ครั้ง (จะมีหน้าต่างให้ login GitHub — login ครั้งเดียว ระบบจำไว้)
   ```powershell
   powershell -ExecutionPolicy Bypass -File tools\sync-from-share.ps1
   ```
4. ตั้งให้ทำงานอัตโนมัติทุก 5 นาที
   ```powershell
   powershell -ExecutionPolicy Bypass -File tools\install-sync-task.ps1
   ```
   - เปลี่ยนความถี่: เพิ่ม `-Minutes 10` · ยกเลิก: เพิ่ม `-Uninstall`
   - ดูประวัติการทำงาน: `tools\sync.log`
   - เครื่องต้องเปิดอยู่และ login ผู้ใช้นั้นไว้ (ล็อกหน้าจอได้)
   - ถ้าเส้นทางโฟลเดอร์เปลี่ยน แก้ค่า `$Source` บรรทัดบนสุดของ `tools\sync-from-share.ps1`

สคริปต์จะคัดลอกไฟล์ `.xlsx` ทุกไฟล์ในโฟลเดอร์ (ไม่รวมโฟลเดอร์ย่อย และไฟล์ชั่วคราว `~$...`) ไปไว้ใน `data/`
ไฟล์ที่ถูกลบออกจากโฟลเดอร์แชร์จะถูกลบออกจาก Dashboard ด้วย · หากไฟล์กำลังถูกบันทึกอยู่จะลองใหม่รอบถัดไป
> ⚠️ รองรับเฉพาะ `.xlsx` — ถ้าเป็น `.xls` (Excel รุ่นเก่า) ให้ Save As เป็น `.xlsx`

## รันบนเครื่องตัวเอง
```bash
pip install openpyxl
python scripts/build_data.py

```

## โครงสร้าง
```
data/                 ไฟล์ Excel ต้นฉบับ
scripts/build_data.py แปลง Excel → site/data.json
site/index.html       หน้า Dashboard (Chart.js)
tools/                สคริปต์ซิงก์จากโฟลเดอร์แชร์ (Windows PowerShell)
.github/workflows/    Build & deploy ขึ้น GitHub Pages อัตโนมัติ
```
